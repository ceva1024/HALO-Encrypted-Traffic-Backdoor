# Security and responsible-use policy

HALO is a research implementation for measuring and improving the robustness
of encrypted-traffic classifiers against backdoor attacks.

Use this repository only on datasets, models, and systems that you own or are
explicitly authorized to test. Do not deploy generated triggers against live
networks or services without written authorization. Remove sensitive capture
metadata before sharing derived datasets or artifacts.

If you discover a vulnerability affecting a third-party system, follow that
party's coordinated disclosure process. Do not include private traffic,
credentials, or exploit details in a public issue.
